Java & Ubuntu Terminal Practice

Simulated Ubuntu shell with basic javac/java, file commands, and nano/vi editing.

student@ubuntu: ~ — web terminal (simulated)
student@ubuntu:~$
Supported commands (implemented in JavaScript):
  • help, clear
  • Navigation: pwd, ls, cd, mkdir
  • Files: touch, cat, rm, nano, vi
  • Java toolchain: javac File.java, java ClassName

Example: nano HelloWorld.java, write a simple program with System.out.println("Hello");, then run javac HelloWorld.java and finally java HelloWorld.

This is a learning simulator that runs fully in your browser (no real JVM or Linux kernel). For full behavior, you can extend terminal.js as an assignment.
