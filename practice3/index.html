Terminal practice tasks

Complete these in the terminal below

  1. Create a working directory ~/lab1 and move into it.
  2. Inside lab1, create three files: report.txt, data.txt, script.sh.
  3. Append a line of text to report.txt and view it using cat, head, and tail.
  4. Use echo and the append operator >> to add three lines to data.txt, then sort and remove duplicates.
  5. Search for a specific word inside data.txt using grep.
  6. Use chmod to make script.sh executable, then run it with bash script.sh.
  7. Create a simple script that uses an if statement to test whether /etc/passwd exists and prints a message.
  8. Create another script using a case statement that prints a different message for inputs start, stop, or anything else.
  9. Write a for loop script that prints the numbers 1 to 5.
  10. Write a while loop script that counts down from 5 to 1.
  11. Simulate checking your IP address and default route using ip addr and ip route.
  12. Simulate downloading a file from the Internet using wget or curl (the terminal will print demo output).
  13. Use sudo in the terminal and observe how the simulator responds to privileged commands.
  14. Simulate viewing system logs with journalctl or tail /var/log/syslog.
  15. Run df -h and du in the simulator to review disk usage concepts.
  16. Explore process monitoring concepts by running top or ps aux (simulated summary).
  17. Pretend to start and enable a service using systemctl start apache2 and systemctl enable apache2.
  18. Create a temporary directory under /tmp and practise removing it safely.
  19. Experiment with /dev/null by redirecting command output there.
  20. Use the $RANDOM variable in a small script that prints ten random numbers.
