1 · Instructions & Data in Python (Colab)

In Google Colab, create a short program that gradually increases and then releases its memory usage. The example below follows the same phases as the simulation. 

# Phase 1: program start (almost no allocations)
import gc, psutil, os, numpy as np

def show_process_memory(label):
    rss = psutil.Process(os.getpid()).memory_info().rss / (1024 ** 2)
    print(f"{label:20s} | memory = {rss:7.1f} MB")

show_process_memory("start")

# Phase 2: program code + small objects
x = 42
msg = "monitoring memory" * 1_000
numbers = list(range(500_000))
show_process_memory("after small data")

# Phase 3: main processing array
main_array = np.ones((4000, 3000), dtype=np.float64)
show_process_memory("after main array")

# Phase 4: temporary scratch space
scratch = np.zeros((3000, 3000), dtype=np.float32)
show_process_memory("after scratch")

# Phase 5: free scratch, keep main data
del scratch
gc.collect()
show_process_memory("after free scratch")

# Phase 6: program finish, free almost everything
del main_array, numbers, msg, x
gc.collect()
show_process_memory("after cleanup")

Each show_process_memory call is a measurement point that you can match with the steps in the simulation.

2 · Monitoring with Linux CLI

While the program is running, use Linux tools in the Colab terminal (or on your own Linux environment) to monitor memory usage.

System-wide memory

# human-readable total, used, free
free -h

# details of total / available memory
grep MemTotal /proc/meminfo
grep MemAvailable /proc/meminfo

Per-process memory

# live process view
top

# restrict view to Python processes
ps aux | grep python

Compare the CLI readings at each program phase with the conceptual memory shown in the simulation panel.

Summary & Reference Notes

Key concepts

  • Allocation: reserving memory for new data structures.
  • Deallocation: releasing memory so it can be reused.
  • Peak usage: the moment when most memory is in use.
  • Monitoring: observing memory with tools and logs.

Connect to theory

  • Relate these steps to logical address spaces and segments.
  • Discuss how paging or virtual memory would affect the picture.
  • Consider fragmentation when many temporary structures are used.
